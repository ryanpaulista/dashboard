# Dashboard de Análise de Dados

Projeto desenvolvido para a disciplina de **Aplicações com Interfaces Ricas**. Trata-se de um dashboard interativo para visualização e análise de dados, construído com o framework Vue.js.

## 📝 Sobre o Projeto

Este dashboard permite a visualização de dados de forma intuitiva e dinâmica. A interface foi projetada para ser responsiva e fácil de usar, oferecendo diferentes tipos de gráficos e filtros para uma análise mais detalhada e eficiente dos dados.

## ✨ Funcionalidades

* **Visualização Dinâmica:** Gráficos interativos (barras, linhas, pizza, etc.) que se atualizam em tempo real.
* **Filtros Avançados:** Capacidade de filtrar os dados por [ex: data, categoria, região, etc.].
* **Design Responsivo:** Interface adaptável para visualização em desktops, tablets e smartphones.

## 💻 Tecnologias Utilizadas

Este projeto será construído utilizando as seguintes tecnologias:

* **Vue.js (v3):** Framework progressivo para a construção da interface.
* **Vite:** Ferramenta de build moderna e ultrarrápida para o frontend.
* **ApexCharts:** Para a renderização dos gráficos.
* **Tailwind CSS:** Para a componentização e estilização da interface (se aplicável).
* **JavaScript / TypeScript:** Linguagem principal do projeto.
